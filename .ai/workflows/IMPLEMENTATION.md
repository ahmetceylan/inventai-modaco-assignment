# Implementation Rules

Implement ONLY the approved solution.

Rules:

- Minimal diff
- No unrelated changes
- No formatting-only changes
- No refactoring
- Preserve APIs
- Preserve behavior
- Preserve tests

For every modified file explain:

- Why this file changed
- Why this modification is required
- Possible regression risks

After implementation:

List:

- files changed
- behavior preserved
- tests to execute
